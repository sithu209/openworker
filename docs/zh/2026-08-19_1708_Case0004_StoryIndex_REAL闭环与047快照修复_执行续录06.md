## 4. 047 第一次 REAL 子工作失敗：不是 CAD 邏輯，而是 authority snapshot 的 Git 假設

OpenWorker 在 terminal join 時取得 child REAL failure：

```text
DWG CAD local execution failed: exit status 1
fatal: not a git repository (or any of the parent directories): .git
scripts/invoke-agent-cad-local.ps1
$commit = (& git -C $RepositoryRoot rev-parse HEAD ...)
```

實際執行 authority root：

`C:\ProgramData\go-tool-runtime\work-agent\authorities\dwg-todo-94e227cee54a`

該 authority 是由 `git archive` 建立的 immutable snapshot；依設計本來就沒有 `.git`。因此 wrapper 要求 `git rev-parse HEAD` 是部署契約錯誤。

### 4.1 修正原則

不得把 snapshot 重新偽裝成 Git checkout，也不得猜 commit。

新版 `scripts/invoke-agent-cad-local.ps1`：

1. 真實 Git checkout：仍使用 Git `HEAD` + `HEAD:OpenCADStudio` tree 作 authority。
2. 安裝 snapshot：讀取 `%ProgramData%\go-tool-runtime\work-agent\authorities\dwg-todo-current.json`。
3. 必須驗證：
   - `authority == dwg-todo`
   - pointer root 與實際 RepositoryRoot 完全一致
   - commit 為 40 字元 SHA
4. snapshot cache key 使用 `snapshot-<commit12>`；不猜 tree hash。
5. legacy cache reuse 只允許真實 Git checkout，因為只有 Git checkout 能以 `git diff` 證明 tree equivalence。
6. snapshot 不存在 / pointer 不匹配 / commit 無效 → fail closed。

修正 commit：`f46cd89537f54fc741b35dd7cb3cdaec5c1b87f2`。
