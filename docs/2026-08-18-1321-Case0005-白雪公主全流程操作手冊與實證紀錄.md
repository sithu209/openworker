## 8. 失敗與負面知識規則

遇到失敗：

```text
讀 OpenWorker failure receipt
-> 問 go-tool failure/negative knowledge
-> 判斷是輸入錯誤、環境錯誤、tool gap 或 transient failure
-> 修真正 owning repo（如必要）
-> 更新 go-tool tool knowledge / negative knowledge
-> 只重跑必要 step
-> 把失敗方法與修法寫回本手冊
```

同一已知錯誤不得無證據重複嘗試。
