- Final Assembly 優先使用 Studio canonical `workspace_artifacts`。

- 選中的 shot artifact 必須是實際存在、非目錄、size > 0 的本地檔案。

- 成功測試改為在 `t.TempDir()` 真正建立非空 shot fixture，不再用不存在檔名假成功。

- 新增永久回歸：provider/source artifact 不存在但 canonical workspace artifact 存在時，Final Assembly 必須使用 workspace copy。
