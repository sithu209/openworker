## 使用者修正的工具選擇規則

案例遇到「不知道該用哪個 capability／queue admin scope」時，不應由案例 workflow 或 ChatGPT 自行翻 YAML 猜答案；工具必須先向 go-tool information authority 查詢。

go-tool 正式查詢：

```text
POST /agent/query
```

必要欄位：`project / workspace_root / question`。

回答 authority：`information_pack / action_capabilities / readiness / prompt`。只能選已註冊 capability；資訊不足時必須說下一步要查什麼，不得猜 execution result。

## OpenWorker 一鍵清隊列

最新版 OpenWorker 已提供：

```text
openworker queue-drain --capability <queue-admin-capability-id>
```

一次呼叫內部完成 query → cancel queued/waiting/in_progress → verify → 必要時重試；只有 `clean=true` 且 `remaining_active=[]` 才成功。此操作為即時運維，不改 Case Worklist canonical step。
