## 8. Blender 空白畫面 Root Cause #1：固定 Euler Camera

原本 request 使用：

```text
location = [8, -8, 6]
rotation_deg = [63, 0, 45]
lens_mm = 50
```

問題是 Blender camera 看向 local `-Z`。把一組固定工程視角 Euler rotation 套上去，**並不能證明 camera 真正朝向 terrain center**。

修復方向：

```python
target = Vector((0.0, 0.0, 0.0))
direction = target - cam.location
cam.rotation_euler = direction.to_track_quat('-Z', 'Y').to_euler()
```

Commit：

```text
f71d96c81ba3b7ea0c10ec4936119c29f5b16c92
fix(blender): aim camera at terrain and reject blank renders
```

同批新增 camera projection gate 與 image non-blank gate。

## 9. Blender Root Cause #2：工程座標正規化矩陣順序錯誤

舊程式：

```python
for o in objs:
    o.location -= center
    o.scale = (visual_scale, visual_scale, visual_scale)
```

對大型投影工程座標而言，這種分開改 `location` 與 `scale` 的語意可能接近：

```text
scale * point - center
```

而正確需求是：

```text
(point - center) * scale
```

因此即使 camera 明確 look-at `(0,0,0)`，實際地形的 transformed center 仍可能離原點很遠。

2026-08-17 run `32007998835` / job `95321389342` 已實際把問題打到新 gate：

```text
terrain semantic visibility failed:
visual center is outside camera frame
```

### 9.1 正式修法

Commit：

```text
430e4a619a47d980d720528d0e8933426c76252d
fix(blender): normalize engineering terrain around true world center
```

目前 `Terrain_To_DXF/main` 實際代碼：

```python
normalize = Matrix.Scale(visual_scale, 4) @ Matrix.Translation(-center)
for o in objs:
    o.matrix_world = normalize @ o.matrix_world
```

也就是讓每個 source point 嚴格轉成：

```text
(point - bounds_center) * visual_scale
```

並增加 invariant：

```text
normalized_center.length <= 1e-4
```

超過即 fail closed。

## 10. Blender Semantic Visibility Gate

Case 0003 後續不能再只看「有 PNG」。正式判斷至少包含以下層次。

### 10.1 Geometry normalization gate

```text
normalized center ≈ (0,0,0)
```

### 10.2 Camera look-at gate

Camera local `-Z` 明確指向 normalized terrain center。

### 10.3 Camera projection gate

使用 `world_to_camera_view()` 投影 transformed terrain bounds：

- 至少有 terrain points 在 camera 前方
- visual center 必須在 frame 內
- projected coverage 必須 `>= 0.01`

### 10.4 Non-blank image gate

原設計對 bounded sample grid 計算 luminance：

```text
luma = 0.2126*R + 0.7152*G + 0.0722*B
```

要求：

```text
luma_range >= 0.02
luma_std   >= 0.005
```

最終成功 marker 必須包含：

```text
BLENDER_VISIBILITY_OK coverage=... luma_range=... luma_std=...
BLENDER_EXECUTION_OK
```

**沒有 `BLENDER_VISIBILITY_OK` 不得視為 Blender rework 完成。**

## 20. GitHub Actions Artifact Storage Quota 注意事項

本案例多次遇到：

```text
Failed to CreateArtifact:
Artifact storage quota has been hit.
```

這是 GitHub Actions storage quota 問題，不等於 Blender/terrain business execution failure。

判斷方式：

- 若核心 REAL step 已 failure，例如 `reference checksum mismatch`、`Render Result unavailable`，業務就是 failure。
- 若核心 REAL step PASS，而最後只有 `actions/upload-artifact` 因 quota 失敗，且 upload step 設 `continue-on-error`，則不能把 quota 誤判成產品失敗。
- 固定 workspace 的實體成果與 job log 仍要保存為 authority；後續 review publication 不應依賴 GitHub artifact 作唯一傳輸。

## 22. Troubleshooting Decision Tree

### A. Job 一直 queued

檢查：

1. `runs-on` 是否含 `UL7`
2. 是否有 UL7 runner online
3. 是否已有正常 repo validation 占用 runner
4. 不要開第二個 competing business run

### B. `reference N checksum mismatch`

處理：

1. 比 expected SHA 與實際 SHA。
2. 不准改 canonical expected SHA 追著現在 bytes 跑。
3. 找 unchanged reference。
4. contract 若允許，建立 rework-local filtered input。
5. 若一張 unchanged reference 都沒有，才重建 reference upstream 並形成新 provenance/revision。

### C. `visual center is outside camera frame`

處理：

1. 檢查 normalization 是否真的是 `(p-center)*scale`。
2. 檢查 normalized center invariant。
3. 檢查 camera local `-Z` look-at target。
4. 不要只調 Euler 角度碰運氣。

### D. `Render Result unavailable`

目前 Case 0003 的最新 blocker。

處理：

1. 已知 PNG 已寫出。
2. 不要取消 non-blank gate。
3. 改為從實際寫出的 PNG 重新 decode/sample。
4. 保留 deterministic luma range/std threshold。
5. rerun 同一 Case 0003 Blender-only rework。

### E. `near-blank image range=... std=...`

代表 camera/render 雖成功，但真正圖像仍缺乏視覺內容。應回到 scene/camera/light/material/geometry 修復，不能降低 threshold 只求過關。

### F. Artifact quota failure

如果只在 upload-artifact：視為 CI storage infrastructure 問題；不要重做 terrain/Blender。

### G. Google Drive credential missing

正式 API publication 要有：

```text
OPENWORKER_GOOGLE_DRIVE_ACCESS_TOKEN
```

或 ADC。兩者都沒有時 fail closed，不能退化成假成功或只 copy local sync folder。

### H. WorkLedger 顯示 REWORK_REQUIRED

先讀 reason / checks / events。禁止手動改 terminal status。
