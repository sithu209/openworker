# 6. 已提煉出的未來操作手冊規則

### 6.1 固定機器上的 private owning repo 不應每次依賴 private checkout secret

如果該機器本來就是長期 REAL executor，應維護 local authority marker：

```text
host + module + root + commit
```

workflow 每次先驗 marker 和實體 HEAD，而不是靠模型猜路徑。

### 6.2 Local authority repair 必須 bounded

不得為了找 repo 無限制掃整台磁碟；只掃正式 runner/cache/authority roots，且用 module identity 驗證。

### 6.3 Worklist gate 要盡量早

Consequential workflow 應在基本 hostname/checkout 後盡早取得 Worklist lease。如此 infrastructure failure 才會留下可解釋 BLOCKED 狀態，而不是散落在聊天中。

### 6.4 修平台缺口不能變成新主線

```text
020 BLOCKED
→ R-0004-020-001
→ repair PASS
→ 自動回 020 READY
→ 正式重跑 020
```

Repair 永遠掛在 parent step 下，不建立另一個平行案例。
