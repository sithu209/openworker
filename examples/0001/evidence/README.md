# 0001 OpenWorker 工程工作基線 — Evidence Index

0001 的 evidence 用來證明通用 worker contract，而不是綁定某一種產物格式。

每次 REAL 驗證至少記錄：

- 使用者任務摘要
- capability id 與 canonical schema
- readiness 結果
- execution / engineering job id
- runner / host identity（如適用）
- 實際工具版本 SHA provenance
- workspace identity
- consequential tool calls / policy disposition
- physical artifact 或 domain result
- artifact accepted / rejected disposition
- Project Work Ledger / evidence correlation

若只能從開發者私有知識或 Action log 才能理解結果，視為資訊工具缺口，不能標記 0001 完成。
