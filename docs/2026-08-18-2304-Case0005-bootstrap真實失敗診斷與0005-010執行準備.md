## 3. 真正根因

`go-tool-runtime` 在 ODA 的正式 local-first 部署不是依賴 source checkout，而是持久安裝於：

`C:\ProgramData\go-tool-runtime\work-agent`

正式部署內容包括：

- `gtr-local-exec.exe`
- `gtr-work-agent.exe`
- `gtr-work-executor.exe`
- `local-queue-authority.json`
- local queue：port `8848`

舊 bootstrap resolver 卻只接受 `go.mod + cmd\gtr-local-exec\main.go` 的 source repo，因此把已部署成功的 go-tool runtime 誤判成不存在。
