exact root cause：PowerShell 5.1 在 inline here-string → `python -` 的路徑改壞 UTF-8 中文 Python source，中文 tuple 被轉成 `??` 並破壞 quote，Python 回：

```text
SyntaxError: invalid syntax
```

這不是 DWG 文字本身的 encoding 問題，而是 workflow source transport encoding 問題。

### 修復

commit：

```text
baf813ff79ec235ca01f3a0ed3fbd00702838122
```

修法：

```text
1. 中文關鍵字以 Python Unicode escapes 表示
2. PowerShell 用 UTF8Encoding(false) 將 Python script 寫到 RUNNER_TEMP
3. python <temp-script> 執行
4. 不再把 CJK Python source 直接 pipe 給 python -
```
