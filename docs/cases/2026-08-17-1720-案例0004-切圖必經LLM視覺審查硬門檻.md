## 3. LLM review 的判斷責任

LLM review receipt 至少要回答：

```text
review_decision: PASS | REWORK
selected_story_region: 明確 region id / bounds
visual_reasoning_summary: 為何這張切圖是目標樓層/區域
reject_regions: 哪些候選不是目標及理由
source_image_sha256: 被審圖片 identity
review_bundle_identity: immutable bundle identity
```

只有 `review_decision=PASS` 才能讓 visual-review repair 通關；`REWORK` 必須維持 BLOCKED，回到重新切圖/補切圖/修候選的 repair 流程，不得進 structural design。
