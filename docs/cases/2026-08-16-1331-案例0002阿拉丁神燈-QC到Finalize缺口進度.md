### 3. ComfyX generic AutoReview 移除有利預設分

審查 ComfyX Intelligence `internal/autoreview` 後確認，舊實作在沒有真實測量值時會使用約 `0.80~0.82` 的預設 technical / narrative / consistency / adherence 分數，存在「未測量也可能 approved / ReadyForAssembly」風險。

已改為 fail closed：

- 必須實際提供 `technical / narrative / characterConsistency / sceneConsistency / promptAdherence` 五個 measured metrics。
- 缺任一 metric，decision 必須為 `retry`，不得 `approved`。
- `ReadyForAssembly` 不得為 true。
- annotations 明確寫 `measurementStatus=incomplete` 與 `missingMetrics`。
- 完全未測量、部分測量都新增永久測試。

### 4. Director typed QC 綁定實際 audited execution
